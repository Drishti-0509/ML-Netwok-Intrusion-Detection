📌 Project Overview


This application detects malicious network traffic using a Random Forest Classifier trained on the NSL-KDD dataset.


The uploaded dataset is automatically preprocessed, categorical features are encoded, numerical features are scaled, and the trained Machine Learning model predicts whether each network connection is Normal or an Attack.
