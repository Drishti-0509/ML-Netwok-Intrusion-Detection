🛡 About Network Intrusion Detection System

AI-Based Cybersecurity using Machine Learning

📌 Project Overview

This project detects malicious network traffic using a Random Forest Classifier. It analyzes network connection records and predicts whether each connection is Normal or an Attack.

📂 Dataset

  • NSL-KDD Dataset
  • 41 Network Features
  • Binary Classification

🤖 Machine Learning Model

  • Random Forest Classifier
  • StandardScaler
  • Label Encoding
